The entry is the heart-hands emoji 🫶 — two hands forming a heart, the warmest thing a stranger can send with no words attached. It reads instantly at any age and in any culture: friendly, open, and kind, with no intimacy, sarcasm, or flirtation — just a small, genuine gesture of goodwill offered to someone you have never met.

## Run it

MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts writes entry.txt containing exactly the single emoji.
